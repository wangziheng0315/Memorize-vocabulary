# H5 学英语单词产品需求文档

## 1. 文档信息

- **文档状态**：提案（Proposal）
- **产品形态**：移动端优先的 H5，兼容桌面浏览器窄屏访问
- **目标用户**：需要按单词书循序记忆英语单词的学习者
- **核心目标**：让用户在 3 个点击内开始/继续学习，并能随时查看学习进度

## 2. 范围与非目标

### 2.1 本期范围

1. 首页、我的两个底部 Tab。
2. 单词书列表与最近学习入口。
3. 邮箱 + 密码登录、注册、退出登录。
4. 单词卡片学习、下一个单词、断点续学。
5. 单词详情页，展示 JSON 中可用的完整释义信息。
6. 用户级学习进度持久化。

### 2.2 暂不包含

- 社交登录、找回密码、邮箱验证。
- 背诵算法（如艾宾浩斯）、错题本、收藏、排行榜。
- 音频文件托管与在线播放实现（本期只保留音标/音频字段接入点）。
- 管理端录入单词书（默认单词书 JSON 已由后端或静态资源提供）。

## 3. 信息架构与路由

| 页面 | 路由建议 | 登录要求 | 说明 |
| --- | --- | --- | --- |
| 首页 | `/` | 否 | 游客只看单词书；登录用户增加最近学习 |
| 我的 | `/me` | 否 | 未登录时打开登录弹窗；已登录时展示账户与进度 |
| 单词学习 | `/study/[bookId]` | 是 | 从断点的下一个单词开始 |
| 单词详情 | `/study/[bookId]/word/[wordId]` | 是 | 展示当前单词完整信息 |

底部导航固定显示两个 Tab：`首页`、`我的`。学习页和详情页保留返回按钮；底部 Tab 可继续显示，避免用户迷路。

## 4. 关键用户流程

### 4.1 游客流程

1. 进入首页，看到全部单词书，不显示“最近学习”。
2. 点击任意单词书或“开始学习”。
3. 跳转到“我的”页面并立即打开登录/注册弹窗。
4. 登录成功后关闭弹窗，返回原单词书；若没有来源页，则回首页。

### 4.2 已登录流程

1. 首页顶部显示“最近学习”（仅在存在进度时显示），按最近学习时间倒序。
2. 点击最近学习卡片，进入该单词书的断点学习。
3. 点击全部单词书中的任意书，若有历史进度则继续，否则从第一个单词开始。
4. 学习页点击单词卡片进入详情页；点击“下一个”保存当前进度并切换。
5. 在“我的”查看每本单词书进度，点击进度项继续学习。

### 4.3 登录/注册流程

- 复用现有 `app/login/page.tsx`、`app/register/page.tsx` 的服务端逻辑：
  - 登录：`signIn('credentials', { email, password })`。
  - 注册：`getUser(email)` 判断重复，`createUser(email, password)` 创建用户。
  - 密码继续由 `app/db.ts` 使用 `bcrypt-ts` 哈希，不在客户端处理明文持久化。
- 将现有表单（`app/form.tsx`）嵌入弹窗；登录和注册用两个状态切换，不重复实现字段。
- 登录成功后的 `redirectTo` 使用来源路径或 `/`，不要继续强制跳转到 `/protected`。
- 需要调整 `app/auth.config.ts` 的授权回调：允许 `/`、`/me` 公开访问，仅保护 `/study/*`；已登录用户不再被全局重定向到 `/protected`。
- 注册重复、密码错误、网络异常必须在弹窗内展示可读错误，保留输入的邮箱。

## 5. 页面需求

### 5.1 首页（登录状态）

1. 顶部：产品名称/问候语，可选显示当前用户邮箱缩写。
2. 最近学习模块：
   - 有数据才渲染；无数据时整个模块（含标题和容器）不占位。
   - 每项显示单词书名称、已学数量/总数、进度条、最近学习时间。
   - 点击整卡进入 `/study/[bookId]`。
   - 默认展示最近 3 本，超过后提供“查看全部”（可在后续迭代实现）。
3. 全部单词书模块：
   - 展示所有可用单词书，至少包含名称、级别/描述、单词总数、开始/继续按钮。
   - 登录用户点击后直接进入对应学习页。
   - 首页展示单词书摘要和总词数；书内全部单词在学习页按顺序访问，避免首页一次性渲染海量词条。
4. 页面滚动区域不被底部导航遮挡，底部安全区使用 `padding-bottom: env(safe-area-inset-bottom)`。

### 5.2 首页（游客）

- 只显示“全部单词书”，隐藏最近学习、个人进度和用户邮箱。
- 点击单词书、开始学习或需要登录的操作：先切换到 `我的` Tab，再打开登录弹窗。
- 单词书仍可浏览基本信息，不泄露用户数据。

### 5.3 我的

**已登录：**

- 头像占位（可用邮箱首字母）、用户邮箱。
- “学习进度”列表：单词书名称、已学/总数、百分比、最近学习时间、继续学习按钮。
- 没有任何进度时显示空状态：“开始选择一本单词书吧”，按钮回首页。
- “退出登录”按钮调用现有 `signOut()`，成功后回首页并清理当前用户视图状态。

**未登录：**

- 显示登录引导卡片和“登录/注册”按钮。
- 页面加载不自动弹窗；从游客首页点击受保护操作时才自动打开弹窗，减少打扰。

### 5.4 登录/注册弹窗

- 居中卡片 + 半透明遮罩，移动端宽度 `calc(100% - 32px)`，桌面端最大宽度 400px。
- 顶部标题和关闭按钮；标题随“登录/注册”状态切换。
- 邮箱输入：`type=email`、必填、浏览器原生格式校验。
- 密码输入：`type=password`、必填，最少 6 位（前后端都校验）。
- 主按钮：登录状态显示“登录”，注册状态显示“注册”。
- 次操作：在“登录”和“注册”间切换；错误文案显示在按钮上方。
- 支持点击遮罩、Esc 关闭；关闭后回到当前页面，不丢失页面滚动位置。
- 必须有可见焦点、`role=dialog`、`aria-modal=true` 和关联标题，满足基本无障碍要求。

### 5.5 单词学习页

- 顶部显示单词书名称、`第 N / 总数 个`、返回按钮。
- 进入规则：
  - `currentIndex` 表示最近一次成功完成的单词下标；没有进度时为 `null`。
  - `nextIndex = currentIndex === null ? 0 : min(currentIndex + 1, total - 1)`。
  - 若上次已完成整本书，再次进入时从第一个单词开始，并提示“已完成，可重新复习”。
- 单词卡片只展示最小信息：
  - `content.word.wordHead`：单词。
  - `content.word.content.trans[0].tranCn`：首条中文释义（没有时显示“暂无释义”）。
  - `content.word.content.sentence.sentences[0]`：一个例句及中文翻译（没有例句则隐藏例句区）。
  - `usphone` / `ukphone`：存在时显示音标。
- 点击单词区域进入详情页；按钮“下一个”保存进度并切换。
- 到达最后一个单词时按钮文案改为“完成本书”；完成后写入完成状态并回到首页或显示完成页提示。
- 防止重复提交：切换期间按钮 disabled；保存失败时保留当前单词并允许重试。

### 5.6 单词详情页

详情页按“有数据才显示”原则渲染以下字段，缺失字段不显示空标题：

| 区块 | JSON 字段 | 渲染方式 |
| --- | --- | --- |
| 标题/音标 | `wordHead`, `usphone`, `ukphone` | 单词大标题，英美音标并列 |
| 核心释义 | `trans[]` | 每项显示 `tranCn`；可折叠英释 `tranOther` |
| 例句 | `sentence.sentences[]` | 英文 + 中文逐条展示；显示 `sentence.desc` |
| 短语 | `phrase.phrases[]` | `pContent — pCn` 列表 |
| 同近义词 | `syno.synos[]` | 词性、`tran`、`hwds[].w` |
| 同根词 | `relWord.rels[]` | 词性、`words[].hwd`、`words[].tran` |
| 记忆方法 | `remMethod.val` | 突出显示，标签取 `remMethod.desc` |

`wordId` 仅用于路由和唯一定位，不直接展示给用户。`ukspeech`、`usspeech` 作为未来音频播放资源标识保留；本期无可用音频 URL 时不显示播放按钮。
`wordRank` 用于单词书内排序；`bookId` 用于关联单词书和进度记录。

## 6. 数据与接口建议

### 6.1 单词书

```ts
type WordBook = {
  bookId: string;
  name: string;
  description?: string;
  level?: string;
  totalWords: number;
  words: WordEntry[]; // 来源为题目给出的 JSON 数组
};
```

单词原始 JSON 作为 `WordEntry` 保存，前端通过适配函数读取字段，避免组件直接依赖深层 JSON 路径。

### 6.2 学习进度

建议新增最小表（或等价存储）：

```ts
type LearningProgress = {
  userId: number;
  bookId: string;
  currentIndex: number | null; // 最近一次成功完成的单词下标，0-based；未开始为 null
  learnedCount: number;
  completed: boolean;
  lastStudiedAt: string;
};
```

- 唯一键：`(userId, bookId)`。
- 点击“下一个”时使用事务或幂等 upsert 更新 `currentIndex`、`learnedCount`、`lastStudiedAt`。
- 百分比：`round(learnedCount / totalWords * 100)`，总数为 0 时显示 0%。
- “最近学习”查询 `lastStudiedAt desc`，只返回当前用户数据。

建议的服务端接口（实现可使用 Server Actions）：

| 能力 | 方法/动作 | 认证 |
| --- | --- | --- |
| 获取单词书列表 | `getWordBooks()` | 否 |
| 获取单词书详情 | `getWordBook(bookId)` | 否（内容可公开） |
| 获取我的进度 | `getProgressForUser()` | 是 |
| 保存学习进度 | `saveProgress(bookId, index)` | 是 |
| 退出登录 | `signOut()` | 是 |

所有需要认证的动作在服务端再次检查 session，不能只依赖前端按钮隐藏。

## 7. 组件与状态建议

- `BottomTabs`：根据当前 pathname 高亮首页/我的。
- `WordBookCard`：接受单词书摘要与 `requiresAuth` 回调。
- `RecentLearningSection`：进度为空时返回 `null`。
- `AuthModal`：管理 `mode=login|register`、打开/关闭和来源路径。
- `WordCard`：只负责最小字段展示，点击触发详情导航。
- `ProgressBar`：统一处理百分比和无数据状态。

客户端状态仅管理弹窗、当前卡片和加载状态；会话、用户信息、进度读取与写入优先放在服务端，避免重复请求和越权。

## 9. 验收标准

### 功能验收

- [ ] 未登录首页只显示全部单词书；最近学习模块完全不渲染。
- [ ] 游客点击单词书后进入我的页并弹出登录/注册弹窗。
- [ ] 登录、注册沿用现有 NextAuth/数据库逻辑，重复邮箱和错误密码有错误提示。
- [ ] 登录用户能看到邮箱、退出登录和学习进度；退出后回到游客态。
- [ ] 最近学习按时间倒序，点击可断点续学。
- [ ] 学习页卡片只展示单词、一个释义、一个例句及可用音标。
- [ ] 点击单词进入详情页，示例 JSON 中存在的字段均能按区块展示。
- [ ] 点击下一个会保存进度；刷新或重新进入后从下一个单词开始。
- [ ] 最后一个单词可完成整本书，进度达到 100%。

### 体验与安全验收

- [ ] 390px 宽度下无横向滚动，底部 Tab 不遮挡内容，兼容刘海屏安全区。
- [ ] 弹窗支持键盘焦点、Esc 和遮罩关闭；按钮有 disabled/loading 状态。
- [ ] 所有进度读写服务端校验当前用户，不能通过修改 `userId` 读取他人数据。
- [ ] 缺失或空数组字段不产生空标题、`undefined` 文本或渲染报错。
- [ ] 单词书总数为 0、进度保存失败、网络异常均有明确空/错误状态。

## 10. 实现顺序（最小可交付）

1. 调整认证回调和登录/注册重定向，抽取可复用服务端 action。
2. 建立单词书读取与 `LearningProgress` 存储。
3. 实现底部 Tab、首页游客/登录双态和单词书卡片。
4. 实现我的页、登录弹窗和退出登录。
5. 实现学习页断点逻辑与进度保存。
6. 实现详情页字段适配、空字段处理和移动端样式。
7. 按验收清单做一轮真实登录、刷新、跨设备（同账号）验证。
